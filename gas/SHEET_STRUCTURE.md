# Google Sheets Structure — Inventory System

Create a new Google Spreadsheet and set up these 5 tabs (sheets).
Run `setupSheets()` from the Apps Script editor to do it automatically.

---

## Sheet 1 — Items

| Column | Header       | Notes                                    |
|--------|--------------|------------------------------------------|
| A      | id           | UUID auto-generated by the backend       |
| B      | barcode      | Unique; this is what the scanner reads   |
| C      | name         | Human-readable item name                 |
| D      | item_type    | `stock` / `asset` / `hybrid`             |
| E      | quantity     | Integer; assets use 0 (out) or 1 (in)   |
| F      | location     | Free text; values come from Locations tab|
| G      | assigned_to  | Blank unless asset is checked out        |
| H      | active       | TRUE / FALSE (soft delete)               |
| I      | created_at   | ISO 8601 UTC timestamp                   |
| J      | updated_at   | ISO 8601 UTC timestamp                   |

---

## Sheet 2 — Movements  *(append-only — never edit rows)*

| Column | Header         | Notes                              |
|--------|----------------|------------------------------------|
| A      | timestamp      | ISO 8601 UTC                       |
| B      | barcode        | The barcode that was scanned       |
| C      | item_name      | Denormalized copy of the name      |
| D      | action         | `in` / `out` / `checkout` / `checkin` / `lookup` |
| E      | quantity_delta | +N or -N (0 for lookups)           |
| F      | user           | Username of who scanned            |
| G      | assigned_to    | Person name (checkout/checkin only)|
| H      | note           | Optional free-text                 |

---

## Sheet 3 — Users

| Column | Header    | Notes                                        |
|--------|-----------|----------------------------------------------|
| A      | username  | Login name                                   |
| B      | pin_hash  | SHA-256 hex of the PIN — never store plain   |
| C      | role      | `admin` or `staff`                           |
| D      | active    | TRUE / FALSE                                 |

---

## Sheet 4 — Sessions

| Column | Header     | Notes                     |
|--------|------------|---------------------------|
| A      | token      | UUID issued on login       |
| B      | username   | Who owns this session      |
| C      | expires_at | ISO 8601 UTC (12 h TTL)   |

---

## Sheet 5 — Locations

| Column | Header | Notes              |
|--------|--------|--------------------|
| A      | name   | e.g. "Shelf A"     |
| B      | active | TRUE / FALSE       |

Default rows seeded by `setupSheets()`:
- Shelf A
- Shelf B
- Storage Room
